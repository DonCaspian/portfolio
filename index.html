// About

A systems-first approach to college projects

Most of my coursework centers on building complete web applications rather than isolated exercises — schema design, server-side logic, and the front end all in one pass. That's meant a lot of time in PHP and MySQL, building the kind of transactional systems real businesses actually run on: bookings, accounts, inventory, payments.

I also step outside the browser when a project calls for it — my Java arcade game Pateros Duckatch was a chance to work with game loops, sprites, and local flavor instead of forms and databases.

I like projects with enough moving parts that they force real decisions: how to structure an admin panel, how to keep a booking system from double-booking a slot, how to make a login flow that isn't an afterthought.
